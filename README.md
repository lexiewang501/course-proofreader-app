# 🎓 課程資料校稿小工具 (Course Proofreader Web App)

專門解決 Word 原稿（`.docx`）與美編排版後宣傳檔（`.pdf`）之間的課程資料逐欄自動比對與抓錯工具。

---

## 🌟 核心功能

1. **雙檔拖曳上傳與智慧解析**：
   - 同時支援拖曳或點選上傳排版前的 Word 原稿（`.docx`）與美編排版後的宣傳成品（`.pdf`）。
   - 內建一鍵載入範例檔案，無須檔案即可快速體驗比對流程。
2. **智慧紅綠燈自動抓錯**：
   - 🟢 **綠燈（通過）**：所有欄位（課程名稱、代碼、時數、點數、費用、教材）完全正確。
   - 🔴 **紅燈（嚴重錯誤）**：時數、點數打錯（例如：Word 寫 14 小時，但 PDF 寫 12 小時）、名稱錯字或費用不符，自動反白標示差異。
   - 🟡 **黃燈（排版提醒）**：課程內容文字微調、全半形空白或教材簡寫差異。
   - ⚪ **灰燈（漏排/未排/略過）**：Word 有此課程但 PDF 漏排，或依規則精簡未排版之欄位（如『課程目標』與『學會技能』）。
3. **課程內容逐條展開對照**：
   - 支援展開課程內容逐條對照清單，核對每條項目是否有漏排或誤植。
4. **外銷與報告工具**：
   - 📋 **複製校稿清單**：一鍵產生條列式修正報告（附頁碼與具體錯誤），方便直接貼到 Teams / Email 傳給美編團隊。
   - 📥 **匯出 CSV**：一鍵下載完整比對試算表。
   - 🖨️ **友善列印**：支援直接列印或另存為 PDF 校稿紀錄。

## 🚀 啟動方式

### Windows 使用者
在專案根目錄中，直接滑鼠左鍵雙擊：
👉 **`啟動校稿工具.bat`**

系統會自動開啟本機伺服器並在預設瀏覽器（Chrome 或 Edge）開啟校稿介面。

### 📌 [v3.5.2] - 正確可使用版本 V3 (重大里程碑版本)
- **多階層清單與 Word 原生 Numbering 完全解析**：
  - 完整解析 Word `word/numbering.xml` 階層樹，支援 `%1..%9` 多層編號、英文字母編號（A/B/C/D）、中文字編號（一、二、三）與特殊符號清單。
  - 解決各課程獨立表格計數器重置與跨欄位序號延續問題，徹底終結章節序號錯位。
- **項目符號形態差異嚴格提醒（黃色警示）**：
  - 當 Word 原稿採用數字編號（1234）而 PDF 排版改用圓點（•）時，嚴格標記為 🟡 黃色提醒：「內文相符，但項目符號形式不同 (Word: 編號 ⇄ PDF: 圓點)」，清楚指出排版樣式落差。
- **複雜與多元版面幾何適應**：
  - **三欄式版面欄間距偵測（3-Column Gutter Detection）**：支援區塊鏈系列（如 BCIC）等緊湊三欄排版，精準拆解多欄大綱與預備知識。
  - **跨行與中英文複合課名萃取**：精準辨識主標題上方的英文前綴行（如 RH358、DO288、RHCSAHo）以及純英文課名（如 AWS 全系列）。
  - **日程大綱分組與大章節階層**：支援「第X天」日程標頭分段識別，以及宣傳品主章節（Flyer Main Chapter）大綱排版。
  - **章節範圍保護**：保留如 `Lab 10-11`、`Day 1-2` 等範圍連字號，避免被誤判定為項目符號腰斬。
- **取消課程與停開防護**：
  - 自動偵測 Word 表格內文字刪除線（`<w:strike>` / `<w:dstrike>`），當全表刪除線比例達 90% 以上時自動判定為停開課程，排除誤報 PDF 漏排。
- **課名校對防呆與結巴去重**：
  - **課名多寫代碼抓漏**：嚴格限制僅在代碼後緊接冒號時才視為標籤前綴，若美編在 PDF 標題多排課程代碼（如 `AIPM`），忠實保留並標註 🟡 黃色警示，杜絕系統自動濾除遮蔽錯誤。
  - **縮寫字首結巴去重**：智慧識別並消除原稿中因版面凸排殘留的縮寫字首結巴（如 `CCN CCNA` 自動校正為 `CCNA`）。
- **全量 10 大系列手冊回歸檢驗**：
  - 內建包含資安、Cisco、RedHat、Python、MSSE、Power Platform、OffSec、OpenSource、Oracle DB、Oracle Java 等 10 大手冊（132 門課程）自動化驗證機制，達成 **0 Red 嚴重誤報**。
