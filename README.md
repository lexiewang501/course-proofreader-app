# 🎓 課程資料校稿小工具 (Course Proofreader Web App)

專門解決 Word 原稿（`.docx`）與美編排版後宣傳檔（`.pdf`）之間的課程資料逐欄自動比對與抓錯工具。

---

## 🌟 核心功能

1. **雙檔拖曳上傳與智慧解析**：
   - 同時支援拖曳或點選上傳排版前的 Word 原稿（`.docx`）與美編排版後的宣傳成品（`.pdf`）。
   - 內建一鍵載入範例檔案，無須檔案即可快速體驗比對流程。
2. **智慧紅綠燈自動抓錯**：
   - 🟢 **綠燈（通過）**：所有欄位（課程名稱、代碼、時數、點數、費用、教材）完全正確。
   - 🔴 **紅燈（嚴重錯誤）**：時數、點數打錯（例如：Word 寫 14 小時，但 PDF 寫 12 小時）、名稱錯字或費用不符，自動反白標示差異。
   - 🟡 **黃燈（排版提醒）**：課程內容文字微調、全半形空白或教材簡寫差異。
   - ⚪ **灰燈（漏排/未排/略過）**：Word 有此課程但 PDF 漏排，或依規則精簡未排版之欄位（如『課程目標』與『學會技能』）。
3. **課程內容逐條展開對照**：
   - 支援展開課程內容逐條對照清單，核對每條項目是否有漏排或誤植。
4. **外銷與報告工具**：
   - 📋 **複製校稿清單**：一鍵產生條列式修正報告（附頁碼與具體錯誤），方便直接貼到 Teams / Email 傳給美編團隊。
   - 📥 **匯出 CSV**：一鍵下載完整比對試算表。
   - 🖨️ **友善列印**：支援直接列印或另存為 PDF 校稿紀錄。

---

## 🚀 啟動方式

### Windows 使用者
在專案根目錄中，直接滑鼠左鍵雙擊：
👉 **`啟動校稿工具.bat`**

系統會自動開啟本機伺服器並在預設瀏覽器（Chrome 或 Edge）開啟校稿介面。

---

## 📁 專案架構

```
├── 啟動校稿工具.bat        # Windows 一鍵啟動腳本
├── index.html              # 前端校稿主介面
├── app.js                  # 核心解析與比對引擎
├── server.js               # 本機輕量 HTTP 伺服器
├── style.css               # 介面樣式與紅綠燈動畫
├── lib/                    # 本地離線解析函式庫
│   ├── jszip.min.js        # docx 解壓縮與 XML 表格解析
│   ├── pdf.min.js          # Mozilla PDF.js 核心引擎
│   ├── pdf.worker.js       # PDF 背景解析工作線程
│   └── tailwind.min.js     # 離線樣式支援
└── README.md               # 專案說明文件
```
